# 更新日志

本项目的所有重要变更都会记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

英文版：[CHANGELOG.md](./CHANGELOG.md)

## [1.3.18] - 2026-11-11

### 新增
- 传输同名冲突弹窗：**替换** / **另存为序号**（`a2.txt` / `folder2`） / **取消**。

### 修复
- 远端删除自动识别文件/目录，并递归删除文件夹（上传后的文件/文件夹可正常删除）。

## [1.3.17] - 2026-11-11

### 新增
- 文件夹递归复制到对侧（上传 / 下载 / 主机互传）。
- 自适应多文件并发（约 8–12 路）+ 单文件分块并行。

### 变更
- 右键「复制到对侧」与拖拽支持文件夹，不再仅限文件。

## [1.3.16] - 2026-11-11

### 变更
- 移除单独的「断开连接」链接；状态徽章即操作入口（悬停显示 连接/断开/重试/取消）。

### 修复
- 切换「文件 / 终端」复用已有会话（工作台不再重载 iframe，终端 WebSocket 保持）。
- 隐藏面板不断开；仅状态控件可断开。

## [1.3.15] - 2026-11-11

### 新增
- 终端/SFTP 连接失败弹窗（超时、认证、拒绝、不可达等），中文说明更清晰。

### 修复
- 点击「终端 / 文件」（或主机卡片）成功/失败后，主机列表状态自动更新，无需点刷新。
- 打开默认双开时始终启动终端会话。

## [1.3.14] - 2026-11-11

### 修复
- 主机列表状态与工作台终端状态跨两个 webview 保持同步。

## [1.3.13] - 2026-11-11

### 变更
- 主机卡片一行四键：**文件 / 终端 / 编辑 / 删除**（去掉「默认」）。
- 点击主机卡片打开默认布局：上文件、下终端。

### 新增
- 面板「关闭」旁增加 **全屏 / 还原**。
- 分隔条 **上下互换**；拖动仍可调整高度。

## [1.3.12] - 2026-11-11

### 修复
- 关闭 SSH 工作台标签后，主机上的「文件 / 终端 / 默认」可重新打开工作台。

## [1.3.11] - 2026-11-11

### 新增
- 工具栏（主题 / 历史 / 字典）跟随当前终端主题配色。

### 修复
- 仅显示 SFTP 或仅显示终端时隐藏无效的关闭按钮。

## [1.3.10] - 2026-11-11

### 变更
- 单面板布局不再显示无效的关闭按钮。

## [1.3.9] - 2026-11-11

### 新增
- 可收起工具栏，给终端更多空间。
- 终端工具条可切换工具栏显示。

### 修复
- 右键操作改用应用内弹窗（兼容 Cursor webview/iframe）。
- 重命名 / 删除 / 新建 / 改权限后文件列表自动刷新。

## [1.3.8] - 2026-11-11

### 修复
- Cursor iframe 中 `prompt()` / `confirm()` 不可用导致右键操作失效。

## [1.3.7] - 2026-11-11

### 新增
- 多文件 / 大文件传输（`fastPut` / `fastGet`）。
- 并发上传、重试、SSH keepalive。
- NDJSON 进度流与速度显示。

## [1.3.6] - 2026-11-11

### 变更
- 权限（`drwxr-xr-x`）显示在文件名下方。
- SFTP 表格列可拖动调整宽度。

## [1.3.5] - 2026-11-11

### 新增
- 中文 SFTP 表格（名称 / 修改时间 / 大小 / 类型）。
- 排序、筛选、面包屑、隐藏点文件开关。
- 右键：复制 / 重命名 / 删除 / 新建 / 改权限。

## [1.3.0] - 2026-11-11

### 新增
- 分栏 UI：主机在 Activity Bar，工作台在编辑器中央。
- 双栏 SFTP、主题、命令历史、Linux 字典。

## [1.2.0] - 2026-11-10

### 新增
- UI 内主机增删改，凭据本地存储。

## [1.0.0] - 2026-11-09

### 新增
- 首个用户级 MCP + Cursor 扩展：主机、Shell、SFTP。
