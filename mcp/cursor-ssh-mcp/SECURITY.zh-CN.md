## 报告漏洞

请**不要**公开提交涉及凭据泄露、鉴权绕过或远程代码执行的 Issue。

建议：

1. 通过 [@A95monster](https://github.com/A95monster) 主页私下联系，或
2. 在仓库可用时使用 **Private vulnerability advisory**。

请尽量包含：

- 受影响版本 / commit
- 复现步骤（**不要**附带真实私钥或密码）
- 影响评估

我们会尽快确认，并在需要时协调修复与披露节奏。

## 使用加固清单

- 优先 **SSH 公钥**；尽量少用长期明文密码。
- Unix 上将 `~/.cursor/ssh-mcp/secrets.json` 与私钥权限设为 `0600`。
- 勿把含密钥、密码或生产 IP 的 `hosts.json` 提交到公开 fork。
- 在 Cursor 中审阅 MCP 工具授权；`ssh_run` 可执行你批准的任意远端命令。
- UI 默认仅监听本机；**不要**把 `3847` 暴露到不可信网络。
- 本工具面向**本机桌面**：MCP 进程以当前用户权限运行。

## 不在范围内

- 同机 Cursor / 操作系统账号已被攻破
- 远端 SSH 配置不当或弱口令
- 粘贴到终端的第三方主题 / 脚本带来的风险
